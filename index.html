Photo Manager Danang Chiropractic

Add photos to your website

Drag a photo onto a slot, then press Publish. This tool puts the file into your website and fills in the right filename for you — no code, no terminal.

First time here? Ask Edouard to add you once as a collaborator on the website repository (repository settings). Then follow these steps.

  1. Open this GitHub page (it opens in a new tab). The needed repo permission is already ticked.
  2. Scroll to the bottom and click Generate token.
  3. Copy the token shown (it starts with ghp_). You will only see it once.
  4. Paste it below and press Connect.

Stored only in this browser, on this device. It is never sent anywhere except to GitHub. Press Sign out any time to erase it. Don't share your token — anyone with it could change the website.

Repository owner? You can use a fine-grained token instead

Create one on the fine-grained tokens page, restrict it to danangchiro-website, and set Contents to Read and write.

Leave these alone unless you know you need to change them. Publishing to a branch other than main will not update your live website.
